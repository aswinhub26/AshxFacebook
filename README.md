# 💎 AshxFacebook (Premium iOS 26 Glass HD Reel Downloader)

An ultra-sleek, premium web application built with **iOS 26 Liquid Glassmorphic Design** to instantly download Facebook Reels and Videos in crisp **1080p / 720p Full HD**.

---

### ✨ Features
- **Ultra HD (1080p/720p) Extraction:** Automatically locates and downloads the highest available stream resolution with zero quality loss.
- **iOS 26 Liquid Glass Theme:** Specular sheen, organic ambient aurora canvas, Cupertino frosted glass cards, and Dynamic Island status pill.
- **Instant Clipboard Paste:** One-tap paste with auto-recognition of Facebook share links.
- **Live HD Player Preview:** Watch the reel inside the app before downloading.
- **Multiple Formats:** Full HD (1080p/720p MP4), Standard SD (480p/360p MP4), and Audio (MP3/M4A).
- **Download Shelf History:** Keeps track of recently saved reels locally.
- **Facebook Share Integration:** Clear guide on how to tap "Share" on Facebook and save instantly.

---

### 🚀 Quick Start

1. Install requirements:
   ```bash
   pip install yt-dlp flask requests
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open in your browser:
   ```
   http://127.0.0.1:5000
   ```
